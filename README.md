# Python Placement Practice

A topic-by-topic collection of Python examples and common coding-interview patterns.
Each numbered folder contains a runnable `practice.py` file with a small example.

## Run an example

From this directory, run any topic with Python 3:

```bash
python3 01-arrays/practice.py
```

Work through the topics in order, then try changing the examples or adding your
own practice problems to the relevant folder.
